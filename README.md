# France Clim Pro — Prospection Bouches-du-Rhône

Application Android pour suivre les demandes de particuliers concernant la climatisation et les chauffe-eau dans les Bouches-du-Rhône.

Fonctions : saisie de demandes, qualification, rendez-vous techniques gratuits, suivi des prospects, partage de texte depuis d'autres applications. Aucune prospection automatique non sollicitée. Données locales sur l'appareil.

## APK

Ouvrir **Actions → Build Android APK → dernier run → Artifacts → France-Clim-Pro-debug**.

Le workflow compile une APK Android debug avec Gradle. La connexion aux sources d'annonces autorisées reste à développer.
